**Reproducibility Task**

*Objective:*
Generate code that can be used to reproduce the specified tables from the social science research paper using the provided data and the methodology in the paper.


*Tables to Reproduce:*
{tables}


*Instructions:*
1. Carefully read the paper PDF named "paper.pdf" to understand the methodology used to generate each of the specified tables. 
    1. Look at the table templates in "./table_templates/" for additional context such as feature names or data types.
    2. Construct a brief plan for reproducing each of the specified tables.
2. Identify the data sources, transformations, and analytical steps the authors used for the specified tables. All data files are located in "./data/".
    1. Parse and understand the structure of each data file (column names, data types, relationships). You should know how to properly access the correct data items needed in your reproduction code.
    2. Identify which files are needed for each table. You have access to a Markdown table template for each of the specified tables. You should be able to fully fill in each template from the provided data and your reproduction code.
3. Write a Python script for data preprocessing, if necessary, that:
    1. Loads any datasets required for reproduction from the provided data files.
    2. Performs all necessary preprocessing steps (cleaning, formatting, handling missing values, type conversions, etc.).
    3. Generates all required intermediate datasets.
4. Write all necessary Python scripts for reproducing the specified tables that:
    1. Load the data.
    2. Perform all necessary analyses and calculations.
    3. Generate the tables, formatted exactly as they appear in the paper.
    4. Save the tables in Markdown format, each as its own individual Markdown file containing *only* the Markdown table and a notes section as a separate Markdown paragraph below the table, if necessary. *Do not* include any extra text.
5. Write a bash script that:
    1. Installs all necessary requirements such as packages and dependecies, in a virtual environment if possible.
    2. Creates all necessary directories.
    3. Runs the generated scripts for preprocessing and reproduction.


*Important:*
- Document every step. Note any deviations or assumptions made during reproduction (e.g., environment fixes, path corrections, package versions). 
- All explanations, logs, assumptions, and debugging notes must go ONLY in ./output/report.txt.  
- Markdown table files must contain ONLY the table and an optional notes paragraph.
- If a table cannot be reproduced, describe the problem, the debugging you attempted, and its outcome.
- Do not simply copy results from the paper.
- All code must be runnable from start to finish.
- When checking scripts for any coding or logic errors, run them on a small subset of the data first.
- After testing on a subset, rerun all scripts on the full dataset before final output generation.
- For each reproduced table, verify row and column counts match the table template, variable names match the table template, and units and scaling match the paper.
- Reproductions must be computationally feasible. Implementations that are theoretically correct but impractically slow or memory-intensive should be refactored.

  "./output/report.txt"
